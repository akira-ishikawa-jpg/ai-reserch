## 2. 世界観

### 2.1 四季大陸

大陸の四方向がそれぞれ永遠の季節に固定されている。人は死ぬと「魂の温度」に応じた季節の国へ転生し、前世の技術だけを才能として引き継いで生まれ変わる。

| 国名 | 季節 | 文化・気質 | 職人の伝統 | カラーパレット |
|------|------|-----------|-----------|--------------|
| **花煙国（かえんこく）** | 春 | 癒し・再生・希望 | 薬師・画師・助産師 | 桜ピンク・白・淡緑 |
| **炎陽国（えんようこく）** | 夏 | 情熱・商業・力 | 鍛冶師・剣士・商人 | 鮮やかな緑・金・橙 |
| **紅葉国（こうようこく）** | 秋 | 知識・記憶・諦観 | 書士・錬金術師・学者 | 深紅・金・琥珀 |
| **氷嶺国（ひょうれいこく）** | 冬 | 精神・静寂・死と再生 | 氷彫師・巫女・霊媒師 | 白・群青・銀 |

国と国の境界には**境界地帯**が存在し、2つの季節が混在する特殊エリアとなっている。

### 2.2 転生と前世の仕組み

- すべての人が「前世の記憶」を持って生まれる
- 前世で磨いた技が今世の才能として宿る
- 鍛冶師の魂は何度生まれ変わっても鉄を打ち、薬師の魂は何度生まれ変わっても薬を調合する
- 主人公だけが唯一「前世の記憶がない」——「呪われた子」と呼ばれる
- 主人公の真実: 前世は「最初の境界師」——四季すべてを渡り歩いていたため、特定の季節の記憶を持たない

### 2.3 灰色化の異変

4つの季節が少しずつ「灰色の無季節」へ収束しつつある。

- 境界エリアが年々広がっている
- 職人たちの前世記憶も薄れてきている
- 桜の色が褪せ、春の力そのものが弱まっている（第1章の導入）

### 2.4 テーマ: 「物の哀れ」

**変わり続けることの美しさを受け入れる。**

- 季節を固定したのは「始まりの職人」（主人公の前世）
- 灰色化は「悪」ではなく、本来の自然な流れへの回帰
- エンディングでは「季節を手放す」選択により、大陸に初めて「本物の四季」が巡る

## 3. ストーリー

### 3.1 全体構成（起承転結）

#### 起: 旅立ち（花煙国〜炎陽国）
- 前世を持たない主人公が、自分の前世を探して4カ国を巡る旅に出る
- 花煙国で紬、炎陽国で辰吾が仲間になる

#### 承: 各国の異変（紅葉国〜氷嶺国）
- 各国で季節の灰色化が進行していることを知る
- 紅葉国で霖、氷嶺国で白音が仲間になる
- 各地のダンジョンで前世の記憶を取り戻していく

#### 転: 目的の崩壊（中盤の裏切り）
- 主人公が4カ国を巡るほど灰色化が加速していることが判明
- 「前世を探す旅」が季節崩壊の引き金だった

#### 結: 敵が正しかった（終盤の裏切り）
- 季節を固定したのは「始まりの職人」——主人公の前世
- 灰色化は本来の自然な流れへの回帰
- 「世界を救う」の意味が丸ごと反転する

#### ハッピーエンド: 本物の季節
- 「季節を手放す」選択の先で、大陸に初めて本物の春夏秋冬が巡る
- 主人公に初めて前世の記憶が宿る——それは「この旅そのもの」
- 仲間たちは前世の重さから解放される

### 3.2 第1章（花煙国）シナリオ詳細

#### プロローグ（dialogue ID: `prologue`）

ナレーションで世界観を導入する。全10行のテキスト。

```
「この世界では、すべての人が『前世の記憶』を持って生まれる。」
「前世で磨いた技——それが今世の才能として宿る。」
「鍛冶師の魂は、何度生まれ変わっても鉄を打つ。
　薬師の魂は、何度生まれ変わっても薬を調合する。」
「『技は、魂が覚えている』——それがこの世界の理。」
「しかし、たった一人だけ——」
「前世の記憶を持たない子供がいた。」
「人々はその子を『呪われた子』と呼んだ。」
「記憶がない。技がない。何者にもなれない——」
「そんな自分が、ただひとつ持っていたもの。」
「それは——すべての季節の技を、見よう見まねで使える力だった。」
```

完了後、自動的に `tsumugi_meeting` へ遷移する。

#### 紬との出会い（dialogue ID: `tsumugi_meeting`）

桜の下で倒れていた主人公を紬が発見。全10行のテキスト。

主要テキスト:
- 紬が自己紹介（霞花里の薬師）
- 主人公に前世の記憶がないことが判明
- 紬:「記憶がないのは、まだ思い出せていないだけ」
- 紬が仲間に加入

完了時のアクション: `addPartyMember: "tsumugi"`

#### 薬師ギルド長の依頼（dialogue ID: `yakushi_intro`）

薬師ギルド長から千年桜の洞の調査依頼。全9行。

主要テキスト:
- ギルド長が主人公の前世のなさに言及
- 桜の色が褪せてきている異変
- 千年桜の洞の調査を依頼

完了時のアクション: `setFlag: "quest_sennen_started"`

#### 千年桜の洞（ダンジョン）

2マップ構成:
1. **千年桜の洞・入口**（25x20）: 3つのシンボルエンカウント + 宝箱1つ
2. **千年桜の洞・深部**（20x15）: ボスエンカウント + セーブポイント

#### ボス前会話（dialogue ID: `before_boss`）

紬が花守の存在と春属性吸収を警告。全5行。

#### 花守戦（ボスバトル）

花守（HP 500）との戦闘。詳細は「敵一覧」セクション参照。

#### 第1章エンディング（dialogue ID: `after_boss`）

花守撃破後、千年桜が本来の色を取り戻す。主人公にかすかな前世の記憶の欠片が宿る。全12行。

主要テキスト:
- 花守が消滅し、春の力が鎮まる
- 主人公に記憶の欠片（桜の下を歩いた記憶）
- 紬:「次は炎陽国に行ってみない？」
- 「第1章『花煙国・春』—— 完」

完了時のアクション: `setFlag: "chapter1_complete"` → `credits` へ遷移

### 5.3 ジョブチェンジの仕組み

1. キャラ加入時: 「今世 × 第1前世」のジョブのみ使用可能
2. 特定地域・イベントで「遺憶（いおく）」を発見 → 新ジョブ解放
3. 各キャラ最大2ジョブ所持
4. ジョブチェンジは**拠点・宿・キャンプのみ可能**（戦闘中は不可）

**実装（`party.gd` の `Character.change_job()`）:**
- `available_jobs` 配列に含まれるジョブIDのみ変更可能
- ジョブ変更時、ステータスをジョブの `baseStats` に置き換え
- HP/MPは現在値と新最大値の小さい方に調整

### 5.4 遺憶の痕（サポートアビリティ）システム

- 各ジョブで習得したパッシブを「遺憶の痕」として刻む
- 別のジョブに装着して使用可能
- **スロット数:** 最大4枠（初期1枠、前世記憶発見ごとに1枠ずつ解放）
- **季節の矛盾ボーナス:** 今世と真逆の季節スキルを装備すると特殊効果+威力上昇

**実装（`party.gd` の `Character`）:**
- `ioku_slots: Array[String]`: 装備中のパッシブIDリスト
- `max_ioku_slots: int`: 最大スロット数（初期1）
- `equip_passive(passive_id)`: スロットに空きがあれば装着
- `_has_passive(passive_id)`: ジョブ固有パッシブまたはスロット装備かを判定

## 6. バトルシステム

### 6.1 「季節の巡り」コアメカニクス

#### 内なる季節ゲージ

各キャラクター・敵が「内なる季節」を持ち、4段階で巡る:

```
春（spring） → 夏（summer） → 秋（autumn） → 冬（winter） → 春...
```

#### 季節属性ダメージ倍率

| 攻撃属性と対象の季節の関係 | 距離 | 倍率 |
|---|---|---|
| **同じ季節**（春→春など） | 0 | 0.1倍（ほぼ無効） |
| **隣接季節**（春→夏、夏→秋など） | 1 | 1.0倍（通常） |
| **対立季節**（春→秋、夏→冬） | 2 | 1.8倍（大ダメージ） |
| **無属性** | — | 1.0倍 |

**実装（`game_state.gd` の `get_season_multiplier()`）:**
```gdscript
static func get_season_multiplier(attack_season: String, target_season: String) -> float:
    if attack_season == "" or attack_season == null:
        return 1.0
    var dist: int = get_season_distance(attack_season, target_season)
    if dist == 0: return 0.1   # 同じ
    if dist == 1: return 1.0   # 隣接
    return 1.8                  # 対立
```

#### 巡る（Advance）

季節を1段階進め、通常攻撃を行う。

- 攻撃者の季節が次に進む
- 進んだ後の季節属性で通常攻撃（物理ダメージ）

#### 留まる（Guard）

今の季節に留まり防御態勢を取る。

- DEF +30%（現在DEFの30%をボーナスとして加算）
- 次のスキル使用時、威力2倍（`guard_boosted` フラグ）

#### 共鳴（Resonance）

同じ季節の仲間と繋がり合わせ技を発動（2章で解禁、プロトタイプ未実装）。

#### 四季の合一（Unity）

パーティ全員の内なる季節が揃った瞬間に発動可能。

**発動条件（`battle_engine.gd` の `check_unity_available()`）:**
- 生存味方が2人以上
- 全生存味方の `current_season` が同一

**季節別効果:**

| 季節 | 効果 | 実装 |
|------|------|------|
| 全員が春 | 味方全員HP全回復 | `a.heal(a.max_hp)` for each alive ally |
| 全員が夏 | 敵全体に ATK × 3.0 のダメージ | `int(actor.atk * 3.0)` per enemy |
| 全員が秋 | 敵全体のスキルを3ターン封印 | `e.skill_seal_turns = 3` |
| 全員が冬 | 敵全体を3ターン行動停止 | `e.stun_turns = 3` |

### 6.2 ダメージ計算式

#### 物理ダメージ

```
base_dmg = max(1.0, ATK × skill_power - (DEF + def_bonus) × 0.5)
season_mul = get_season_multiplier(skill_season, target_season)
guard_boost = 2.0 if guard_boosted and skill_power > 1.0, else 1.0
random = 0.9 + rand() × 0.2  (0.9〜1.1)
damage = max(1, int(base_dmg × season_mul × guard_boost × random))
```

#### 魔法ダメージ

```
base_dmg = max(1.0, MATK × skill_power - (MDEF + def_bonus) × 0.5)
season_mul = get_season_multiplier(skill_season, target_season)
guard_boost = 2.0 if guard_boosted, else 1.0
random = 0.9 + rand() × 0.2
damage = max(1, int(base_dmg × season_mul × guard_boost × random))
```

#### 回復量

```
base_stat = max(MATK, ATK)
amount = base_stat × skill_power × (0.9 + rand() × 0.2)
healed = min(max_hp - current_hp, int(amount))
```

#### クリティカル

- 基本クリティカル率: 5%
- パッシブ「烈火の魂」装備時: +15%（合計20%）
- クリティカル時の演出: font_size 72 + 金色 + 画面フラッシュ（ダメージ倍率は未実装、演出のみ）

### 6.3 敵AI（行動決定ロジック）

**`battle_engine.gd` の `decide_enemy_action()`:**

```
1. HP比率を算出: hp_ratio = hp / max_hp
2. 使用可能スキルを列挙（スキル封印中でなく、MP足りるもの）

3. HP 30%以下の場合:
   → 使用可能スキルの中で最も power が高いスキルを選択
   → 季節相性が最も有利なターゲットを選択

4. 通常時:
   → 40%の確率でスキル使用（ランダム選択）
   → 60%の確率で通常攻撃（巡るとして扱う = 季節も進む）

5. ターゲット選択（_pick_best_target）:
   → スキルの季節属性と味方の現在季節の相性倍率が最大のターゲットを選ぶ
```

**AIタイプ:**

| タイプ | 説明 | 対象 |
|--------|------|------|
| `basic` | 上記の標準ロジック | 花精、霧狐 |
| `aggressive` | 上記の標準ロジック（同一） | 花蜂 |
| `boss` | 上記の標準ロジック（同一） | 花守 |

### 6.4 ターン管理フロー

```
1. start_turn()
   ├── turn_count += 1
   ├── 敵の季節タイマー進行
   │   └── season_timer >= season_interval → 季節を巡る
   ├── 生存ユニットを速度順にソート（同速はランダム）
   └── phase = "input"

2. ユニットごとの行動
   ├── 味方の場合 → プレイヤーがコマンド選択
   └── 敵の場合 → decide_enemy_action() で自動決定

3. execute_action(action)
   ├── "advance" → 季節を進める + 通常攻撃
   ├── "guard" → 防御 + guard_boosted フラグ
   ├── "skill" → MP消費 + スキル効果適用
   ├── "item" → アイテム使用
   └── "unity" → 四季の合一

4. 行動後の処理
   ├── current_index += 1
   ├── 次の生存ユニットまで進む
   ├── スタン中のユニットはスキップ
   └── 全員行動完了 → phase = "turnEnd"

5. end_turn()
   ├── 全ユニットの tick_end_of_turn()
   │   ├── skill_seal_turns -= 1
   │   ├── stun_turns -= 1
   │   ├── def_bonus = 0
   │   └── is_guarding = false
   └── start_turn() で次ターン開始

6. 勝敗判定（execute_action 内で毎回チェック）
   ├── 敵全滅 → phase = "victory"
   └── 味方全滅 → phase = "defeat"
```

### 6.5 EXP配分

**戦闘終了時の獲得EXP（`battle_engine.gd` の `calc_exp_reward()`）:**

```
total_exp = Σ (enemy.level > 0 ? enemy.level : 1) × 10 + enemy.max_hp
```

**分配（`party.gd` の `distribute_exp()`）:**

```
each = total_exp / 生存メンバー数（端数切り捨て）
```

生存メンバー全員に均等分配。レベルアップ時はHP/MP全回復。

## 9. 探索システム

### 9.1 グリッド移動の仕様

- タイルベースのグリッド移動
- 1マスずつ移動
- 通行可能タイル: EMPTY(0), FLOOR(2), DOOR(4), ENTRANCE(8), SAVE(6), CHEST(5), NPC(7)
- 通行不可: WALL(1), WATER(3)

**入力マッピング（project.godot）:**

| アクション | キー |
|-----------|------|
| move_up | W / 上矢印 |
| move_down | S / 下矢印 |
| move_left | A / 左矢印 |
| move_right | D / 右矢印 |
| interact | Space / Enter |
| cancel | Escape |

### 9.2 シンボルエンカウント

- 敵がマップ上にシンボルとして表示される
- プレイヤーがシンボルに接触するとバトル開始
- ダンジョンマップの `encounters` 配列に固定配置

**敵シンボルの仕様:**
- 座標は `encounters` 配列で定義
- `is_boss: true` のエンカウントはボス戦
- ボス戦前にはストーリーイベント（`before_boss`）を挟む

### 9.3 NPC会話トリガー

- NPCに隣接した状態で `interact` アクション → 会話開始
- 会話データは `StoryData.get_dialogue(dialogue_id)` で取得
- 会話中は探索入力を無効化（`DialogueEngine.is_active` で判定）

### 9.4 マップ遷移

- `TILE_ENTRANCE(8)` タイルに乗ると遷移
- 遷移先は `exits` 配列で定義: `target_map` + `target_x` / `target_y`
- マップ読み込みは `MapsData.get_map(map_id)` で取得

### 9.5 セーブポイント

- `TILE_SAVE(6)` タイルで `interact` アクション → セーブ実行
- セーブデータ: JSON形式で `user://save_{slot}.json` に保存
- 保存項目: party, flags, gold, current_map, current_season, day_count, play_time

### 9.6 宝箱

- `chests` 配列で定義（座標、アイテム、開封状態）
- 隣接して `interact` → アイテム取得 + `opened: true` に変更
- 開封済み宝箱は再取得不可

### 11.4 クロスフェード仕様

**AudioManager（Autoloadシングルトン）の実装:**

- BGMプレイヤー2台（A/B）によるクロスフェード
- SEプレイヤープール: 8台（同時再生最大8音）
- デフォルトフェード時間: 1.0秒

**クロスフェードの処理:**
1. 新しいプレイヤーにストリームをセット、volume_db = -80.0 で再生開始
2. Tweenでパラレル実行:
   - 新プレイヤー: -80.0dB → 目標dB（デフォルト -6.0dB）, Ease IN, CUBIC, 1.0秒
   - 旧プレイヤー: 現在dB → -80.0dB, Ease OUT, CUBIC, 1.0秒
3. フェード完了後、旧プレイヤーを停止

**音量制御:**
- BGM/SE各0.0〜1.0のリニア値で管理
- dB変換: `20 * log10(linear)` (linear=0のとき -80.0dB)
- デフォルト音量: BGM 0.8, SE 0.8（-6.0dB）

### 14.4 パーティクル設定

#### 実装方式

GPUParticles3Dではなく、SphereMeshベースのコードパーティクルを使用。

- メッシュ: SphereMesh（radius=0.04, 8 segments）
- マテリアル: StandardMaterial3D（emission + transparency）
- ライフタイム管理: Tween + `queue_free()`
- オブジェクトプーリング: ダメージポップアップのみプール

**理由:** モバイル対応で軽量、Tweenでの精密制御が可能、季節色の動的変更が容易。

#### パーティクルタイプ一覧

| タイプ | 関数名 | 用途 |
|--------|--------|------|
| バースト | `_spawn_burst_particles()` | ダメージインパクト・シールド破壊 |
| 収束 | `_spawn_converge_particles()` | 詠唱・季節変更の集束 |
| 上昇 | `_spawn_rising_particles()` | 回復・炎柱 |
| 軌道 | `_spawn_orbit_particles()` | バフオーラ・渦巻き |
| 滞留 | `_spawn_lingering_particles()` | デバフの靄 |
| 落下 | `_spawn_falling_particles()` | 花びら・吹雪・紅葉 |
| ビーム | `_spawn_beam_to_center()` | 四季の合一 |

#### 環境パーティクル（バトルフィールド）

| 季節 | パーティクル内容 | 間隔 |
|------|----------------|------|
| 春 | 桜ピンクの花びら、ゆっくり落下（揺らぎあり） | 2.0秒ごとに5個 |
| 夏 | 金色の光の粒、下→上に上昇（陽炎） | 3.0秒ごとに3個 |
| 秋 | 琥珀色の落ち葉、斜めに落下（揺らぎあり） | 2.5秒ごとに5個 |
| 冬 | 白い雪粒、まっすぐ落下（揺らぎ少） | 3.0秒ごとに5個 |

実装: `start_ambient_particles()` / `stop_ambient_particles()`

### 14.5 シェーダー設定（battle_flash.gdshader）

5つの機能を1シェーダーに統合:

| 機能 | uniform | 用途 |
|------|---------|------|
| ダメージフラッシュ | `flash_intensity` (0→1→0), `flash_color` | 被ダメ時点滅。白=通常、赤=大ダメ、金=クリティカル |
| オーラ | `aura_intensity`, `aura_color`, `aura_speed` | バフ/季節変更時のキャラ発光。UV端ほど強い輪郭発光+ノイズ波紋 |
| 季節カラーモーフ | `season_color_from`, `season_color_to`, `season_morph` (0→1) | 季節切替時にティントを滑らかに遷移 |
| アウトライン | `outline_width`, `outline_color` | 選択中/ターゲット中のキャラにアウトライン |
| 頂点膨張 | （aura系と連動） | オーラ時に頂点が法線方向に波打ちながら膨張 |
