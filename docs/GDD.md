# 四季廻りの職人（Shiki-Meguri no Shokunin）— Game Design Document

> **ジャンル：** HD-2D ターン制RPG（スマートフォン・横画面）
> **価格：** 1章無料 / 全章パック 700円（買い切り）/ ガチャなし
> **タグライン：** 「技は、魂が覚えている。」

---

## 1. ゲーム概要

ブレイブリーデフォルト・オクトパストラベラーの系譜を継ぐ、スマートフォン向けHD-2D RPG。
「前世×今世のジョブマトリクス」と「四季が巡るバトルシステム」を核に、
美しい四季の大陸を旅する王道かつユニークなRPG体験を提供する。

### コアの面白さ
- **前世×今世で16種に変化するジョブシステム**
- **季節の巡りを読む駆け引きバトル**
- **HD-2Dで描かれる春夏秋冬の圧倒的なビジュアル**
- **王道の骨格 × 中盤・終盤の2段階の裏切り**

---

## 2. 世界観

### 四季大陸

大陸の四方向がそれぞれ**永遠の季節**に固定されている。
人は死ぬと**「魂の温度」**に応じた季節の国へ転生し、前世の技術だけを才能として引き継いで生まれ変わる。

| 国名 | 季節 | 文化・気質 | 職人の伝統 | カラーパレット |
|------|------|-----------|-----------|--------------|
| **花煙国（かえんこく）** | 春 | 癒し・再生・希望 | 薬師・画師・助産師 | 桜ピンク・白・淡緑 |
| **炎陽国（えんようこく）** | 夏 | 情熱・商業・力 | 鍛冶師・剣士・商人 | 鮮やかな緑・金・橙 |
| **紅葉国（こうようこく）** | 秋 | 知識・記憶・諦観 | 書士・錬金術師・学者 | 深紅・金・琥珀 |
| **氷嶺国（ひょうれいこく）** | 冬 | 精神・静寂・死と再生 | 氷彫師・巫女・霊媒師 | 白・群青・銀 |

国と国の境界には**境界地帯**が存在し、2つの季節が混在する特殊エリアとなっている。
桜と紅葉が同じ木に咲き、雪の上に夏の花が咲く——HD-2Dの最大の見せ場。

### 世界の異変

4つの季節が少しずつ**「灰色の無季節」**へ収束しつつある。
境界エリアが年々広がり、職人たちの前世記憶も薄れてきている。

## 3. ストーリー

### 構造：王道の骨格 × 2段階の裏切り

#### 王道として守る部分
- 主人公は特別な存在（前世がない唯一の人間）
- 4カ国を旅して仲間を集める
- 世界を救う明確な目的
- 仲間との絆が力になる

#### 中盤の裏切り：目的の崩壊
主人公が4カ国を巡るほど、**灰色化が加速**していることが判明。
「前世を探す旅」が、実は季節崩壊の引き金だった。
仲間との関係・集めてきた記憶すべてが揺らぐ。

#### 終盤の裏切り：敵が正しかった
季節を固定したのは「始まりの職人」——主人公の前世。
灰色化は「悪」ではなく、**本来の自然な流れへの回帰**だった。
固定された季節こそが、世界への干渉だった。
「世界を救う」の意味が丸ごと反転する。

#### ハッピーエンド：本物の季節

「季節を手放す」選択の先——

- **固定された季節**から**本物の季節**が訪れる
- 大陸に初めて「春夏秋冬が巡る本物の四季」が訪れる
- 主人公に初めて「前世の記憶」が宿る——それは**この旅そのもの**
- 主人公の旅が「次の誰かの前世」になった
- 仲間たちは前世の重さから解放され、初めて「今」だけを見て笑っている

テーマ：**物の哀れ** ——変わり続けることの美しさを受け入れる

## 4. 主人公・仲間キャラクター

### 主人公（プレイヤーキャラ）

- **名前・性別：** プレイヤーが設定
- **特徴：** この世界で唯一「前世の記憶がない」人間
- **呼ばれ方：** 「呪われた子」
- **旅の動機：** 自分の前世を探して4カ国を巡る
- **真実：** 主人公の前世は「最初の境界師」——四季すべてを渡り歩いていたため、特定の季節の記憶を持たない
- **ジョブ：** 旅の中で前世の記憶のかけらを拾い、徐々に解放される

### 仲間4人

4人の前世は**たすきがけ**になっており、「四季は本来巡るもの」というテーマをキャラクターの出自レベルで体現している。

```
紬（春）→ 前世：冬
辰吾（夏）→ 前世：秋
霖（秋）→ 前世：春
白音（冬）→ 前世：夏
```

---

#### 紬（つむぎ） — 花煙国の薬師

| 項目 | 内容 |
|------|------|
| 今世 | 花煙国（春）の薬師 |
| 前世 | 氷嶺国（冬）の霊媒師 |
| テーマの感情 | **未練（みれん）** |
| 加入時期 | 序盤・花煙国 |
| 加入の理由 | 主人公の体を心配して同行 |

**人物像：**
前世で誰も救えなかった記憶が消えない。だから今世も薬師になった。
穏やかで面倒見がいいが、「助けられなかった人」の話になると表情が曇る。

**前世回想章：**
冬の霊媒師として、死にゆく人の魂を送る仕事をしていた。
しかしある疫病で村が全滅し、送ることしかできなかった自分に絶望した。
「次こそは——救う側に」という未練が、春の薬師として転生させた。

**守破離の成長：**
- 守：前世の調合術通りに作る
- 破：「この患者には教科書通りでは間に合わない」と気づく
- 離：病気を治すだけでなく、死を穏やかにする薬も作れるようになる
  - ジョブ名変化：「薬師」→「**送り花（おくりばな）**」

---

#### 辰吾（しんご） — 炎陽国の鍛冶師

| 項目 | 内容 |
|------|------|
| 今世 | 炎陽国（夏）の鍛冶師 |
| 前世 | 紅葉国（秋）の書士 |
| テーマの感情 | **覚悟（かくご）** |
| 加入時期 | 序盤・炎陽国 |
| 加入の理由 | 季節の異変を調べるため |

**人物像：**
寡黙だが芯が強い。「自分の命一つで季節の崩壊が止まる」と知っている。
それでも旅を続ける——その覚悟を誰にも語らない。

**前世回想章：**
秋の書士として世界の記録を残す仕事をしていた。
しかし記録した「世界の真実」が都合の悪い権力者に焼かれ、
「言葉では守れない。次は——自分の手で形を作る」と決意した。

**守破離の成長：**
- 守：師匠直伝の鍛造術を忠実に再現する
- 破：「壊すことしかできない」という自分の武器の本質に直面
- 離：壊すためではなく、守るための刃を打てるようになる
  - ジョブ名変化：「鍛冶師」→「**守刃（まもりば）**」

---

#### 霖（りん） — 紅葉国の書士

| 項目 | 内容 |
|------|------|
| 今世 | 紅葉国（秋）の書士 |
| 前世 | 花煙国（春）の画師 |
| テーマの感情 | **忘却（ぼうきゃく）** |
| 加入時期 | 中盤・紅葉国 |
| 加入の理由 | 主人公の前世の記録を知っている |

**人物像：**
記憶を写す職人なのに、前世の記憶だけが全く見えない。
知識は豊富だが感情を出すのが苦手。本を通じてしか世界と繋がれない。

**前世回想章：**
春の画師として、見たものを絵に残していた。
しかし「描いた絵が本物より美しい」と言われたことで、
自分が記録ではなく「嘘」を描いていたのではないかと苦悩した。
「次こそは——ありのままを残す」と、装飾を排した書士に転生。

**守破離の成長：**
- 守：事実だけを正確に記録する
- 破：「事実だけでは真実は伝わらない」と気づく
- 離：事実と感情の両方を記録に込められるようになる
  - ジョブ名変化：「書士」→「**語り継ぎ（かたりつぎ）**」

---

#### 白音（しらね） — 氷嶺国の巫女

| 項目 | 内容 |
|------|------|
| 今世 | 氷嶺国（冬）の巫女 |
| 前世 | 炎陽国（夏）の剣士 |
| テーマの感情 | **諦念（ていねん）** |
| 加入時期 | 中盤・氷嶺国 |
| 加入の理由 | 自分の前世と主人公が関係していると気づく |

**人物像：**
すべては無常と悟りきっている。感情を捨てた理由を誰にも言わない。
冷たく見えるが、誰よりも世界の変化を恐れている。

**前世回想章：**
夏の剣士として、最強を誇っていた。
しかし守りたかった人を守れず、「力では何も救えない」と悟った。
「次こそは——静かに、祈りで救う」と、巫女に転生。

**守破離の成長：**
- 守：感情を排し、祈りの型を忠実に守る
- 破：旅の中で再び「怒り」という感情が蘇る
- 離：感情を否定せず、祈りに乗せて力に変える
  - ジョブ名変化：「巫女」→「**灯巫女（ともしみこ）**」

---

### 前世のたすきがけ構造

```
     春（紬の今世）──→ 冬（紬の前世）
      ↑                    ↓
  秋（霖の前世）       夏（白音の前世）
      ↑                    ↓
  秋（霖の今世）←── 夏（辰吾の今世）
                   辰吾の前世は秋
```

4人の前世が一つの環になっており、「四季は本来巡るもの」をキャラクター設計で体現。

## 5. バトルシステム：「季節の巡り（めぐり）」

### コアコンセプト

各キャラクターの内側に**「内なる季節ゲージ」**があり、4段階で巡り続ける。

```
春（はる）→ 夏（なつ）→ 秋（あき）→ 冬（ふゆ）→ 春…
```

今の内なる季節と一致するスキルは**威力1.5倍**。
対立する季節（春⇔秋・夏⇔冬）のスキルは**0.7倍**。

### 3つの基本コマンド

| コマンド | 意味 | 効果 |
|---------|------|------|
| **巡る（めぐる）** | 季節を1段階進める | 次ターン、内なる季節が変化。攻撃的に使う |
| **留まる（とどまる）** | 今の季節に根を張る | 防御+30%・今の季節スキルの威力が次ターン2倍 |
| **共鳴（きょうめい）** | 同じ季節の仲間と繋がる | 内なる季節が同じ仲間と「合わせ技」を発動 |

### 敵の季節システム

敵も**「内なる季節」**を持ち、自然に巡っている。

| 攻撃の関係 | 効果 |
|-----------|------|
| 敵と**同じ季節**で攻撃 | 吸収される・ほぼ無効 |
| 敵と**隣の季節**で攻撃 | 普通のダメージ |
| 敵と**逆の季節**で攻撃 | **大ダメージ＋特殊効果** |

敵の内なる季節はキャラクターの**オーラの色**で視覚的に表現。

**駆け引き：** 「敵の季節が変わるのを読んで、タイミングよく仕掛ける」
→ プレイヤーの「巡る/留まる」の判断と直接噛み合う

### 四季の合一（しきのがいつ）

パーティ全員の内なる季節が**揃った瞬間**に発動する全体奥義。

| 季節 | 効果 |
|------|------|
| 全員が春 | 大地を花畑に変え、全体蘇生+HP全回復 |
| 全員が夏 | 炎嵐を起こし、全敵に壊滅的ダメージ |
| 全員が秋 | 記憶の嵐、敵の特技を全封印 |
| 全員が冬 | 時を凍らせ、次の3ターン敵の行動を完全停止 |

狙って揃えるのが難しいからこそ価値がある。

### メカニクス解禁タイムライン

複雑さは「一気に教えない」ことで解決する。

| タイミング | 解禁される要素 |
|-----------|--------------|
| 序章 | 巡る / 留まる だけ。季節ゲージの見方を覚える |
| 1章（春の国） | 属性の弱点・強さを学ぶ。留まる→威力2倍のコンボ体験 |
| 2章（夏の国） | 共鳴コマンド解禁。初の四季の合一を偶然起こさせる演出 |
| 3章（秋の国） | ジョブチェンジ解禁。遺憶の痕スロット最初の2枠 |
| 中盤 | スロット3・4枠目解放。季節の矛盾ボーナスを「発見」させる |
| 終盤 | 全要素が揃い、戦略の深みが最大化 |

### バトルの手触りを一文で

> **「自分の季節が来るまで我慢するか、無理やり動かすか」の2択。**
> これだけ覚えれば遊べて、上達するほど奥が見えてくる。

## 6. ジョブシステム

### 前世×今世マトリクス（16種）

キャラクターの「今世の国籍」と「前世の国籍」の組み合わせで固有職が決まる。

```
            前世の国
            春          夏          秋          冬
今  春 │ 双春の薬師  │ 焔薬師    │ 追憶の画師 │ 送り人     │
世  夏 │ 花剣士      │ 烈火の剣士│ 学剣士     │ 蒸気技師   │
の  秋 │ 命の錬金術師│ 戦学者    │ 双秋の書士 │ 霜の賢者   │
国  冬 │ 死花術師    │ 冷炎巫者  │ 骨書術士   │ 虚無の巫女 │
```

### ジョブ解放の仕組み

ジョブは最初から自由に変えられない。前世の記憶を発見するたびに解放される。

```
① キャラ加入時：「今世 × 第1前世」のジョブだけ使える
          ↓
② 特定の地域・イベントで「遺憶（いおく）」を発見
          ↓
③ 「今世 × 第2前世」の新ジョブが解放・切り替え可能に
          ↓
④ 最終的に各キャラ最大2ジョブを所持
```

ジョブチェンジは**拠点・宿・キャンプのみ可能**（戦闘中は不可）。

### 遺憶の痕（いおくのあと）— サポートアビリティ

各ジョブでアビリティを習得すると「遺憶の痕」として刻まれ、
**別のジョブに装備して使える**ようになる。

- **スロット数：** 最大4枠（前世記憶を掘り起こすたびに1枠ずつ解放）
- **季節の矛盾：** 今世と真逆の季節スキルを装備すると「矛盾の技」として特殊効果＋威力上昇

**例：** 春の薬師が冬の「死霊術」を装備 → 「送り花」発動：敵を仮死状態にしてHP吸収

## 7. 探索・進行システム

### 国の巡り方

**固定順（春→夏→秋→冬）＋ 境界地帯が自由探索**

```
花煙国（春）──[春夏の境界]──炎陽国（夏）──[夏秋の境界]──紅葉国（秋）──[秋冬の境界]──氷嶺国（冬）
                ↑ 自由探索                    ↑ 自由探索                    ↑ 自由探索
```

- メインストーリーは固定順
- 境界地帯だけ自由に探索できる
- サブクエスト・隠しジョブ・前世回想章のトリガーが境界地帯にある
- 「寄り道したい人はできる、したくない人は素通りできる」

### 各国の基本構成

| 要素 | 内容 | 役割 |
|------|------|------|
| 街（1〜2箇所） | アイテム・ジョブチェンジ・住民との会話 | 拠点 |
| ダンジョン（2〜3箇所） | ストーリー進行・ボス・前世回想章トリガー | メインコンテンツ |
| フィールド | 街とダンジョンを繋ぐだけ・広くしない | 移動経路 |

### ダンジョン設計思想

**コンパクト探索型** — 「広さより密度」

| 対策 | 内容 |
|------|------|
| オートマップ | 行った場所が自動記録。未探索エリアが一目でわかる |
| 探索度表示 | 「このダンジョン 70%探索済み」で達成感が生まれる |
| 中間セーブポイント | モバイルの中断を前提に、ボス前に必ず置く |
| 分岐に意味を持たせる | 寄り道の先に必ず何かある（遺憶の痕・前世回想章など） |

### エンカウント方式

**シンボルエンカウント** — 敵が見えており、触れると戦闘。
敵を避けながら探索ルートを選ぶ判断が生まれる。

## 10. HD-2Dビジュアル方針

| エリア | 背景 | パーティクル | 光源 |
|--------|------|-------------|------|
| 花煙国（春） | 霞がかった桜山・水墨画的な墨線 | 花びらが常にゆっくり舞う | 柔らかい朝の白光 |
| 炎陽国（夏） | 熱帯のジャングル・活火山 | 陽炎・蛍 | 強烈な真上からの金色の太陽光 |
| 紅葉国（秋） | 朱塗りの廃神殿・苔むした石畳 | 落ち葉が横に流れる | 低い斜光・夕焼けの橙 |
| 氷嶺国（冬） | 氷の宮殿・凍った湖面 | 粉雪・吐息 | オーロラ・月光の青白 |
| 境界地帯 | 2つの季節が混在するありえない風景 | 混合パーティクル | 2つの光源が共存 |

**最大の見せ場：境界エリア**
- 桜と紅葉が同じ木に咲く
- 雪の上に夏の花
- 氷と炎が共存
- HD-2Dの奥行きを最大限に使った「ありえない美しさ」

## 付録：設計ルール

### ジョブ設計ルール
- **同国×同国（双〇〇）：** 純粋・極端・わかりやすい強さ
- **逆属性（春×冬など）：** 矛盾ゆえの特殊能力・高リスク高リターン
- **隣接する季節：** バランス型・使いやすい

### 難易度設計
- 序盤はシンプルに世界観を伝える
- 中盤からジョブの選択が重要になる
- 終盤は全要素を駆使する戦略バトル

### モバイル最適化
- セッション想定：1回10〜20分
- 中間セーブを多めに
- 操作はすべて片手親指で届く範囲に
