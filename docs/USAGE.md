# 操作マニュアル（MVP版）

## 1. サービス情報の取得
- トップ画面で「サービスURL」を入力し「サービス情報を取得」ボタンを押す
- サービス名・概要・想定課題カテゴリが表示される

## 2. 課題起点での提案率測定
- 「課題文」「サービスURL」「AIツール」「競合サービス（任意）」を入力
- 「計測・探索を実行」ボタンを押す
- AIごとのサービス出現回数・競合出現回数・各AI回答と提案レベルが表示される

## 3. Deep Research（課題探索）
- 「サービスURL」「AIツール」「競合サービス（任意）」を入力
- 「Deep Research（課題探索）を実行」ボタンを押す
- 候補課題一覧・頻出課題上位3件・集計結果が表示される

## 4. 実行ログ・集計データ
- すべての実行結果は `data/` ディレクトリに自動保存される（JSON形式）

## 注意事項
- OpenAI APIキーが必要です（.envに設定）
- AI実行には数分かかる場合があります
- 本MVPは検証・探索用途です
